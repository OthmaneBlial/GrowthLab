# GrowthLab 0.1.0-alpha.1 — source prerelease

**Your growth ideas. Real diffs.** GrowthLab turns competing growth proposals
into isolated code changes you can inspect, check and explicitly select.
This alpha demonstrates the local loop with a bundled fictional product.

## What you can try today

- Import a local Git product with reviewed `growthlab.yaml` permissions.
- Compare three changes from one frozen baseline in isolated worktrees.
- Run actual validation commands and inspect failures, diffs, logs and sealed evidence.
- Inspect archived static candidate pages on desktop and phone.
- Explicitly select an eligible candidate, export its patch or apply it to a clean baseline.
- Download private-by-default offline HTML/Markdown reports and recover interrupted attempts.
- Run a key-free fictional replay demo with one deliberate heading failure.

Replay proposals are **SIMULATED**, executed checks **OBSERVED**, and growth
outcomes **UNTESTED**. Passing checks do not prove conversion lift. The demo
does not automatically select, apply, commit or publish changes to your product.

## Install from the tagged source

```sh
git clone --branch v0.1.0-alpha.1 https://github.com/OthmaneBlial/GrowthLab.git
cd GrowthLab
pnpm -C ui install --frozen-lockfile
pnpm -C ui build
cargo install --path . --bin growthlab --locked
growthlab demo
```

Requires Git, Rust, Node.js 22 and pnpm 10. No Docker is required. Configured
validation requires OS confinement: local macOS checks pass using
`sandbox-exec`; the Linux Bubblewrap backend exists but its runtime proof is
pending. Windows validation confinement is not implemented and is refused.

GitHub provides tagged source archives. **No standalone binaries or installers
are attached.** Cross-platform packaging, complete binary-distribution notices
and target runtime verification remain release gates.

## Local validation

- Rust: 914 tests per binary; 912 passed, zero failed and two inherited ignored tests.
- UI: 167 passed, zero failed or skipped.
- Formatting, Clippy, UI types, styles and builds passed locally.
- Fresh locked release build passed on macOS arm64; version `0.1.0-alpha.1`
  uses the `development` build channel.
- Real release-binary CLI import, selected delivery and HTTP demo smokes passed,
  including exact embedded UI assets and check exits `0/0/0`, `2/0/0`, `0/0/0`.
- Actual dashboard and website desktop/phone browser flows passed locally;
  published website assets were verified over HTTPS.

**All six GitHub Actions workflows remain disabled at the user's request.**
Validation runs locally; this release does not enable or dispatch CI.

## Current limits

Overall progress is **about 45%, a subjective estimate against the complete
specification**. Native-agent battle verification, remaining launcher and
selected-delivery recovery, the complete tree/settings/localization interface,
a real demo recording and richer visual evaluation, broader inputs/playbooks,
real outcome measurement and portable installers remain pending.

This source alpha is not the complete product or the credible production release
described in the specification. No measured growth, production readiness or
demonstrated adoption is claimed. Optional providers require separately reviewed
authorization. Reports omit private context by default; deliberate disclosure
still requires reviewing their contents before sharing.
