# GrowthLab v0.1.0-alpha.13

GrowthLab v0.1.0-alpha.13 is a source prerelease for the local SEO growth
workspace.

## Included

- Sealed comparisons and shareable reports now expose the
  `static-render-hints-v1` rubric when local Chromium checks are available.
- The observed score is decomposed into viewport coverage, horizontal overflow,
  visible copy and capture metadata integrity for the desktop and phone targets.
- The dashboard and report output keep the observed rubric separate from the
  estimated SEO/page-quality hints and from untested growth outcomes.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The rubric summarizes one sanitized static document in the locally
installed Chromium build; it is not Lighthouse, a Core Web Vital, an
accessibility audit, a visual regression result, real-user performance evidence
or a growth result. Native provider execution, provider adapters, continuous
recording, Windows validation and measured SEO outcomes remain unverified.
GitHub Actions is disabled; validation runs locally.
