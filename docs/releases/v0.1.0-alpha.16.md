# GrowthLab v0.1.0-alpha.16

GrowthLab v0.1.0-alpha.16 is a source prerelease for the local SEO growth
workspace.

## Included

- Ready sealed previews now wait for the local Chromium load lifecycle before
  recording navigation timings, so desktop and phone checks can expose DOM-ready
  and load observations instead of serializing only parser-time values.
- Comparison rows, the dashboard and private JSON, Markdown and HTML reports
  now include the optional `browser-timing-hints-v1` rubric when timing entries
  are available.
- The rubric decomposes first-paint hints, DOM content loaded, load complete and
  timing metadata integrity with transparent local thresholds and explicit
  provenance.
- Documentation and the bundled smoke test cover the timing trace and its
  limits, including the first-rendered-frame proxy used when a `file://` page
  exposes no paint entry.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The timing rubric is one sanitized local Chromium observation; it
is not Lighthouse, Core Web Vitals, accessibility, visual regression,
real-user performance or growth evidence. Provider adapters, native-agent
execution, continuous recording, full visual regression/accessibility
validation, Windows validation and measured SEO outcomes remain unverified or
pending. GitHub Actions is disabled; validation runs locally.
