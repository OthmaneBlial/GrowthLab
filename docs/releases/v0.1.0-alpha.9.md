# GrowthLab v0.1.0-alpha.9

GrowthLab v0.1.0-alpha.9 is a source prerelease for the local SEO growth
workspace.

## Included

- Inspectable page-quality hints beside the SEO page-hygiene rubric in battle
  comparisons and shareable HTML/Markdown reports.
- Five conservative source-level signals: mobile viewport, named links and
  buttons, labelled form controls, parser-blocking resource hints and claim
  guardrails.
- Explicit **ESTIMATED** provenance, recommendations and limits that keep the
  hints separate from measured growth, Lighthouse, accessibility and ranking
  claims.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. Native provider execution, provider adapters, continuous recording,
browser-based visual/performance evaluation, Windows validation and measured SEO
outcomes remain unverified. GitHub Actions is disabled; validation runs locally.

Passing local checks does not establish rankings, traffic, conversions or
production readiness.
