# GrowthLab v0.1.0-alpha.18

GrowthLab v0.1.0-alpha.18 is a source prerelease for the local SEO growth
workspace.

## Included

- Added `accessibility-structure-v1`, an estimated six-dimension rubric for
  document language, landmarks, heading hierarchy, image alternatives, named
  controls and form labels.
- Exposed the rubric in comparison rows, the dashboard and private Markdown,
  HTML and JSON reports with recommendations, evidence and explicit limits.
- Extended the real bundled smoke to verify the rubric and raised the subjective
  full-spec progress estimate to 84%.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The accessibility rubric is an archived-HTML source review; it is
not a WCAG, keyboard, screen-reader, assistive-technology, visual-regression,
performance or growth result. Provider adapters, native-agent execution,
full visual regression, Windows validation and measured SEO outcomes remain
unverified or pending. GitHub Actions is disabled; validation runs locally.
