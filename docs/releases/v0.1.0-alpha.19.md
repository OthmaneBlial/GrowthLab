# GrowthLab v0.1.0-alpha.19

GrowthLab v0.1.0-alpha.19 is a source and macOS arm64 prerelease for the local
SEO growth workspace.

## Included

- Added a downloadable `growthlab-v0.1.0-alpha.19-macos-arm64.tar.gz` containing
  the native `growthlab` CLI, README, demo and distribution guides, MIT license,
  OpenResearch attribution notice and all six checked-in dependency notices.
- Added a matching SHA-256 checksum file and aligned Cargo package metadata so
  `growthlab --version` reports `0.1.0-alpha.19`.
- Added an offline archive verifier that checks checksums, rejects traversal and
  unexpected links, and runs the binary when the target matches the host.
- Kept the archive source-first and local: it includes no provider credentials,
  installer signing, notarization or telemetry claims.

## Limits

The binary is validated on macOS arm64 only. Linux and Windows binaries,
installers, signing and notarization remain pending. Provider adapters,
native-agent execution, full visual regression and assistive-technology
accessibility validation, and measured SEO outcomes remain unverified. GitHub
Actions is disabled; validation runs locally.
