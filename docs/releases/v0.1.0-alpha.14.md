# GrowthLab v0.1.0-alpha.14

GrowthLab v0.1.0-alpha.14 is a source prerelease for the local SEO growth
workspace.

## Included

- The workspace experiment map now groups persisted hypotheses into accessible
  role branches so positioning, conversion and onboarding work can be scanned
  without losing the shared goal context.
- Existing hypothesis IDs remain stable through battle preparation and variant
  records, keeping each visible branch linked to its frozen evidence lineage.
- The public status, README and Pages site now report this map improvement and
  the current subjective full-spec estimate of about 79%.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The map is a read-only grouped view in this alpha; editing,
settings localization, provider adapters, native-agent execution, continuous
recording, full browser quality/performance evaluation, Windows validation and
measured SEO outcomes remain unverified or pending. GitHub Actions is disabled;
validation runs locally.
