# GrowthLab v0.1.0-alpha.15

GrowthLab v0.1.0-alpha.15 is a source prerelease for the local SEO growth
workspace.

## Included

- Comparison rows now expose the persisted `hypothesisId` that produced each
  battle variant.
- Private JSON, Markdown and HTML reports preserve that ID so a reviewer can
  trace a branch from the workspace experiment map through its frozen contract,
  checks and archived evidence.
- The dashboard shows the lineage ID on each competing variant while keeping
  product paths and private context out of default reports.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. Hypothesis lineage is recorded and inspectable, but the experiment
tree is not yet a fully editable or localized settings surface. Provider
adapters, native-agent execution, continuous recording, full browser
quality/performance evaluation, Windows validation and measured SEO outcomes
remain unverified or pending. GitHub Actions is disabled; validation runs
locally.
