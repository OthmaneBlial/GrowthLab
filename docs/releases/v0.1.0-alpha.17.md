# GrowthLab v0.1.0-alpha.17

GrowthLab v0.1.0-alpha.17 is a source prerelease for the local SEO growth
workspace.

## Included

- Added a continuous 30-second H.264 product walkthrough captured from an
  isolated Chrome profile. The recording shows the public GrowthLab site, its
  real browser evidence and the bundled SEO growth demo without exposing the
  working desktop.
- Updated the README, demo guide, progress snapshot and project site to make the
  recording easy to find while keeping the compact eight-second reel available.
- Raised the subjective full-spec progress estimate to 82% because the
  continuous walkthrough is now published and verified.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The recording is a product walkthrough, not an SEO, accessibility,
performance or conversion result. Provider adapters, native-agent execution,
full visual regression/accessibility validation, Windows validation and measured
SEO outcomes remain unverified or pending. GitHub Actions is disabled; validation
runs locally.
