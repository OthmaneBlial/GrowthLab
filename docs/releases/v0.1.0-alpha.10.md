# GrowthLab v0.1.0-alpha.10

GrowthLab v0.1.0-alpha.10 is a source prerelease for the local SEO growth
workspace.

## Included

- The local `seo-audit` command now returns both the eight-dimension SEO page
  hygiene rubric and the five-dimension page-quality hints in JSON and Markdown.
- Public HTTPS page audits expose the same page-quality hints after their
  bounded, robots-aware read-only fetch.
- The dashboard shows quality hints for public page reviews as well as archived
  battle candidates, with direct recommendations and limits.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. Native provider execution, provider adapters, continuous recording,
browser-based visual/performance evaluation, Windows validation and measured SEO
outcomes remain unverified. GitHub Actions is disabled; validation runs locally.

Page-quality hints are source-level **ESTIMATED** guidance. They do not run
Lighthouse, a browser timing trace or a screen reader, and passing them does not
establish rankings, traffic, conversions or production readiness.
