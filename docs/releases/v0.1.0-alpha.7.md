# GrowthLab v0.1.0-alpha.7

GrowthLab v0.1.0-alpha.7 is a source prerelease for the local SEO growth
workspace.

## Included

- Public GitHub checkout import into a caller-selected new local destination.
- Local CSV comparisons that keep variant baselines separate by distribution or
  channel, with descriptive intervals and explicit provenance.
- Workspace experiment map with three untested SEO growth branches.
- Battle preparation that preserves persisted hypothesis IDs and evidence
  lineage in each isolated variant.
- Updated README, roadmap and public documentation with current local checks.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. Native provider execution, provider adapters, continuous recording,
richer visual/performance evaluation, Windows validation and measured SEO
outcomes remain unverified. GitHub Actions is disabled; validation runs locally.

The demo and starter branches are labelled **SIMULATED** or **UNTESTED** where
appropriate. Passing local checks does not establish rankings, traffic,
conversions or production readiness.
