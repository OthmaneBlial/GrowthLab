# GrowthLab v0.1.0-alpha.11

GrowthLab v0.1.0-alpha.11 is a source prerelease for the local SEO growth
workspace.

## Included

- Ready static preview candidates now attempt verified Chromium captures at both
  desktop (1280 × 900) and phone (390 × 844) sizes.
- The candidate inspector shows the archived capture that matches the selected
  viewport, with the PNG dimensions and SHA-256 digest.
- The real bundled-demo smoke requires and verifies both capture endpoints when
  local Chromium is available.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. Captures are render artifacts, not visual regression, accessibility,
performance, ranking, traffic or conversion evidence. Native provider execution,
provider adapters, continuous recording, browser-based visual/performance
evaluation, Windows validation and measured SEO outcomes remain unverified.
GitHub Actions is disabled; validation runs locally.
