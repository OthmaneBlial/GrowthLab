# GrowthLab v0.1.0-alpha.20

GrowthLab v0.1.0-alpha.20 is a source-first prerelease for the local-first SEO
growth workspace. It includes a manually validated macOS arm64 archive and a
Linux x86_64 musl archive whose structure was verified locally from this exact
tag. Linux runtime and installer proof remain pending.

## Included

- Added explicit `--include-visuals` CLI and `includeVisuals=true` API report
  controls. Reports remain capture-free by default; opt-in HTML and Markdown
  exports embed only verified archived desktop and phone PNGs with dimensions
  and SHA-256 digests.
- Added an explicit disclosure in HTML and Markdown that embedded captures are
  local render artifacts, not accessibility, performance, visual-regression or
  growth results.
- Extended the real screenshot-required bundled demo smoke to assert default
  report privacy and six opt-in captures across its three sealed variants,
  without contacting provider CLIs.
- Refreshed the public documentation page so the progress estimate and report
  disclosure behavior match the checked-in status and live site.
- Attached a Linux x86_64 musl CLI archive and checksum built from the exact
  alpha.20 tag. Its archive structure and notices are verified; the ELF was not
  run on Linux here.

## Validation

- `cargo test --locked report -- --test-threads=1` passed locally for both
  binaries, including opt-in encoding and the 4 MiB bound.
- `GROWTHLAB_REQUIRE_SCREENSHOT=1 python3 scripts/test-growth-demo.py` passed
  against the real CLI/HTTP demo with three sealed attempts and six embedded
  captures.
- GitHub Actions remains manually disabled; validation runs locally only.

## Limits

This source prerelease does not claim native provider execution, provider
adapters, measured SEO lift, full visual-regression or assistive-technology
certification, Linux runtime proof, Windows binaries, signed binaries,
installers, notarization or adoption. The Linux archive is a structure-verified
cross-target artifact; it is not runtime evidence.
