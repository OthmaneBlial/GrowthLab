# GrowthLab v0.1.0-alpha.12

GrowthLab v0.1.0-alpha.12 is a source prerelease for the local SEO growth
workspace.

## Included

- Ready static previews now record observed local Chromium render checks beside
  their verified desktop (1280 × 900) and phone (390 × 844) PNG captures.
- The candidate inspector exposes viewport coverage, visible copy length,
  horizontal-overflow status and optional local navigation/paint timings for the
  selected viewport.
- The bundled demo smoke requires both captures and checks when local Chromium
  is available, while legacy archives remain readable without the new metadata.

## Limits

This is a tagged source archive. It does not include standalone binaries or
installers. The checks describe one sanitized static document in local Chromium;
they are not Lighthouse, Core Web Vitals, accessibility, visual-regression,
real-user performance or growth evidence. Native provider execution, provider
adapters, continuous recording, Windows validation and measured SEO outcomes
remain unverified. GitHub Actions is disabled; validation runs locally.
