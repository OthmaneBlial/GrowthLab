# Community discussion prompts

Use these prompts when repository discussions are enabled. This document does
not claim any discussion, community participation or adoption already exists.

- Which local product workflow would you entrust to an isolated growth agent,
  and which paths or actions would you prohibit?
- What explicit evidence would make you choose one landing-page candidate over
  another when you have no traffic analytics?
- Share a reproducible battle on a public demo product: hypothesis, source
  commit, changed files, validation failures, rubric and result provenance.
- Which activation or onboarding hypothesis did deterministic checks help you
  reject before publishing it?
- What needs to appear in a report before you are comfortable sharing it?
