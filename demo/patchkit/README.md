# PatchKit: fictional, key-free GrowthLab fixture

PatchKit is a fictional maintainer tool. These pages are original demo content,
not a real service, customer endorsement or growth-outcome dataset.

`growthlab demo` copies the baseline into a new private, lab-owned Git repository,
freezes one contract and executes three declared replay proposals using the real
GrowthLab engine. The second proposal deliberately omits the required `<h1>`;
its structural command fails with exit 2. Links and prohibited-claim checks still
run. Files, diffs, logs, source snapshots and outcomes are real local artifacts.

The Node validator checks only its explicit structural/link/claim contract. It
does not prove comprehensive HTML validity, accessibility, performance or growth.
Proposals are SIMULATED, deterministic checks OBSERVED and growth outcomes UNTESTED.

No Docker, provider account, external URL, JavaScript page execution, telemetry,
product apply or publishing is needed. See `docs/demo.md` for the app workflow.
